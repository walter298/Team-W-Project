# Overview

This repository contains the code for an implementation and simulation of Kalman filtering. 


# Files

game.py is an interactive pygame for visualizing Kalman filtering. Users can move their mouse around and see how the Kalman filter adjusts and estimates position. A regression model is added as a baseline. Users can also change some of the parameters of the game, including the standard deviation for the noise of the observations and the number of points the regression model fits on. 

1d.py is the file for simulating 1d motion for numerous starting parameters.
